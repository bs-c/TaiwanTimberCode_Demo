一、斷面幾何性質（矩形斷面，寬 b × 高 h）

斷面積 & 慣性矩

A = b × h　　(cm²)
Ix = b·h³ / 12　(cm⁴，強軸 x-x)
Iy = h·b³ / 12　(cm⁴，弱軸 y-y)
迴轉半徑：ix = √(Ix/A) = h/√12，iy = b/√12

彈性斷面模數

Zex = b·h² / 6　(cm³，x-x 軸)
Zey = h·b² / 6　(cm³，y-y 軸)
設計撓曲應力：Fb = |M| / Ze

二、長期容許應力（短期容許應力之 1/2）

Lfc = Sfc / 2　　（長期壓應力）
Lft = Sft / 2　　（長期拉應力）
Lfb = Sfb / 2　　（長期撓曲應力）
Lfs ← 依樹種分類查表（另列）
Sfc, Sft, Sfb 依材料等級查「材料性質」表；Lfs 依樹種分類查剪力表。

三、挫屈細長比 λ

有效計算長度

lkx = Kx × (Lb/L₀)x × L₀
lky = Ky × (Lb/L₀)y × L₀
Kx, Ky：有效長度比（兩端固接=0.5；一端固一端鉸=0.7；兩端鉸=1.0；懸臂=2.0）

細長比

λx = lkx / ix
λy = lky / iy
λ = max(λx, λy)　（取控制值）

四、挫屈折減係數 η

λ ≤ 30　　　→　η = 1.000（短柱，無挫屈折減）
30 < λ ≤ 100　→　η = 1.3 − 0.01·λ
λ > 100　　→　η = 3000 / λ²
長期容許挫屈壓應力 Lfk = η·Lfc；短期 Sfk = η·Sfc

五、尺寸調整係數 Cf（撓曲）

h ≥ 30 cm　→　Cf = (30/h)1/9
h < 30 cm　→　Cf = 1.0
x-x 向以 h（斷面深度）代入；y-y 向以 b（斷面寬度）代入。
尺寸因子對大斷面有折減效果（h=30 時 Cf=1.0；h=45 時 Cf≈0.96）。

六、橫向挫屈調整係數 Cb（強軸撓曲）

計算參數

Ck = 0.8 × √(E//y-y / Lfb-xx)
Cs = √(le·h / b²)
le = (Lb/L₀)x × L₀（強軸有效撓曲長度）
E//y-y：y-y 向彈性模數；Lfb-xx：強軸長期容許撓曲應力

Cb 判斷

Cs ≤ 10　　→　Cb = 1.000
10 < Cs < Ck　→　Cb = 1 − (Cs/Ck)^(4/3)
Cs ≥ Ck　　→　Cb = 0.4·E//y-y / (Cs²·Lfb-xx)
弱軸撓曲通常不發生橫向挫屈，取 Cb-yy = 1.0

七、軸力應力比 DCRc / DCRt

受壓（P < 0）

設計壓應力：Fc = |P| / A
長期：DCRc,L = Fc / (η·Lfc) = Fc / Lfk
短期：DCRc,S = Fc / (η·Sfc) = Fc / Sfk

受拉（P ≥ 0）

設計拉應力：Ft = P / A
長期：DCRt,L = Ft / Lft
短期：DCRt,S = Ft / Sft

八、撓曲應力比 DCRb

設計撓曲應力：Fb3 = |M3| / Zex　（x-x 強軸）
　　　　　　　Fb2 = |M2| / Zey　（y-y 弱軸）
長期：DCRb3,L = Fb3 / (Lfb-xx · Cfx · Cbx)
　　　DCRb2,L = Fb2 / (Lfb-yy · Cfy · Cby)
短期：DCRb3,S = Fb3 / (Sfb-xx · Cfx · Cbx)
　　　DCRb2,S = Fb2 / (Sfb-yy · Cfy · Cby)

九、P-M 複合應力比（軸彎交互作用）

長期：DCRP-M,L = DCRb3,L + DCRb2,L + DCRc,L （或 DCRt,L）
短期：DCRP-M,S = DCRb3,S + DCRb2,S + DCRc,S （或 DCRt,S）
▶ 檢核條件：DCRP-M ≤ 1.0（超過表示不足）

十、剪應力比 DCRs

剪應力斷面因子 α = 1.5（矩形斷面）
設計剪應力：Fs3 = V3 / A，Fs2 = V2 / A
長期：DCRs3,L = α·Fs3 / Lfsx　；　DCRs2,L = α·Fs2 / Lfsy
短期：DCRs3,S = α·Fs3 / Sfsx　；　DCRs2,S = α·Fs2 / Sfsy
▶ 檢核條件：DCRs ≤ 1.0
